# 深宫弈 · 竖屏沉浸版（iOS）

宫斗文字游戏《深宫弈》的竖屏大改版，WKWebView 壳加载本地 `Shengongyi/index.html`，不联网也能玩。

## 改了什么（相对女朋友的 Muse 做的原版 `upload.html`）

- **瘦身**：8.11MB → 1.27MB。16 处实景图其实只有 4 张不同，去重后压到宽 1200 / JPEG q72；删 Google Fonts 外链，改系统字体。
- **竖屏**：整站按 430px 竖屏重排，状态栏横滑、底部大按钮、单手能点；只锁定竖屏（Portrait）。
- **少文字**：日志/弹窗/说明默认只露两行（弹窗六行），点一下展开全文；数值改图标+数字条。
- **多图像**：场景图全屏底 + Ken Burns 缓慢缩放（不是真视频）；对话改视觉小说式（大立绘 + 底部气泡）。
- **存档**：localStorage 自动存档（每次渲染后存）+ 开局页“继续上局”+ 底部存档浮钮。
- **向导式建角**：一步一页共 5 步（定你自己 / 六维属性 / 八项才艺 / 定皇帝 / 确认总览），顶部步骤条 1/5～5/5，上一步/下一步，第 5 页有选秀预测（表现分/开局宠爱/初封）。
- **人物立绘**：全部手绘 SVG，无网图无版权图。原 portraitSVG 的半身像放大重做成全身像（200×340），主角/皇帝/6 个可攻略角色/主要嫔妃各有各的脸型、发型发饰、服饰颜色款式与配饰，贴合性格。
- **画风标准（统一古风）**：女——交领右衽汉服/宫装（襦裙·袄裙·宫装·披风），发髻+簪钗步摇花钿，柳叶眉、凤眼（细长小眼，绝不大眼萌系）、樱桃口；男——束发+玉冠/金冠/乌纱，交领长袍/蟒袍/铠甲，腰封玉佩。全部汉族服饰，不混其他民族与现代元素。
- **地图**：保留原 4 张故宫实景图做场景底；地图页新增手绘竖屏宫城示意图，14 个地点都可点前往，金点数字表示此刻有人。

## 没做到的

- **真视频没加**：每场景一段视频体积会爆炸，改用 Ken Burns 缓慢缩放营造动感。
- **地点仍共用实景图**：原文件只有 4 张不同的实景图，14 个地点只能共用，无法无中生有；示意图是手绘的。

## 打包

GitHub Actions（macos-26）打未签名 IPA：`Shengongyi-unsigned.ipa`，用全能签导入签名后安装到 iPhone。
